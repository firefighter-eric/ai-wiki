# Llama 家族

## 简介

`Llama` 是 Meta 开放权重语言模型家族的总入口。这里聚合初代 `LLaMA`、`Llama 2`、`Code Llama` 与 `Llama 3` 的代际关系；具体模型的训练与能力主张仍回到各自概念页和 summary 核对。

## 关键属性

- 类型：开放权重基础模型家族
- 主线节点：`LLaMA -> Llama 2 / Code Llama -> Llama 3`
- 组织方式：家族导航与代际关系，不替代单代模型页

## 相关主张

- 初代 `LLaMA` 建立了这一开放基础模型路线的起点。
- `Llama 2` 将 foundation model 与 chat 对齐模型一起系统发布，`Code Llama` 则形成代码专门分支。
- `Llama 3` 延续家族路线，并扩大模型、数据与能力范围；具体规模和训练口径以对应来源为准。
